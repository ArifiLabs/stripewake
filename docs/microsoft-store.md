## Submission options
Publish as soon as certified. Restricted capability (runFullTrust) justification:

> Stripewake is a classic Win32 tray app (plain C) packaged as MSIX. It needs runFullTrust to call desktop APIs
> that app-container apps cannot use: SetThreadExecutionState to keep the PC awake, the Power Management API
> (PowerReadACValueIndex / PowerWriteACValueIndex) to hold the power plan's display, dim and lid timeouts while ON
> and restore them when OFF, Shell_NotifyIcon for the tray icon, and DDC/CI monitor brightness (dxva2) for Dim when
> away. It does not elevate, installs no services or drivers, and makes no network connections.

## Next version (the automation path)
Partner Center keeps all of the above; a new version only needs a new package and, if wanted, a new "What's new"
line. To do that without the website: Microsoft's Store submission API (the `msstore` CLI or the
`microsoft/store-submission` GitHub Action) can upload the new .msix and submit, driven by this record. It needs a
one-time link between Partner Center and a Microsoft Entra app (tenant ID, client ID, client secret) that only the
account owner can create.
